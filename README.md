# AiLite Neo using MIT App

AiLite Neo can be controlled and programmed using MIT App Inventor, a visual programming tool that allows users to create mobile apps. By connecting AiLite Neo to the MIT App Inventor interface, users can design and develop custom projects that interact with the robot, utilizing its various sensors and capabilities.
